Страница «О себе» на HTML без CSS и JavaScript. Основной язык — английский. Используется стандартное оформление браузера.

## Проекты

1. Составление переводов подкастов YouTube-канала Ruri Ohama.
2. Улучшение и тренировка AI-перевода в Yandex Translate.
3. Разметка для модели проекта EngCLI.

EngCLI — приложение, работающее в терминале. Локальная модель определяет уровень английского пользователя. После передачи ссылки на ролик на YouTube приложение создаёт и сохраняет карточки Anki по содержанию видео, отбирая только релевантные уровню пользователя.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

Для запуска через локальный сервер из папки репозитория:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Реализованные элементы

- `header`: имя, фамилия и заголовок страницы.
- `main`: основной контент.
- Две секции `section`: «Навыки» с маркированным списком и «Проекты» с нумерованным списком из трёх языковых проектов.
- `aside`: изучение английского языка.
- Одно изображение-аватар с атрибутами `src`, `alt`, `width`, `height`.
- Форма: «Имя» (`type="text"`), «Email» (`type="email"`), «Сообщение» (`textarea`) и кнопка отправки. У всех полей есть `name`, `placeholder` и связанный `label`.
- Ссылки на разделы страницы и описание EngCLI.
